## Native ownership and behavior

`PeGame` owns HP, inventory and the new`float medpack_cooldown`; `pe_game_use_slot` consumes one925, immediately adds350 HP up to`max_hp`, and starts ten seconds of cooldown. Empty inventory, cooldown, dead player or malformed health/timer state cannot consume the item. Full-HP use is permitted. Inventory right-click, keyboard quickslots and right-click quickslots all reach the same function. Quickslot aliases cannot bypass cooldown; a stack shortcut remains assigned after its last item is consumed.

The existing simulation health clock decrements the medpack timer independently of the juice cooldown/buff. It is scaled simulation time, not the accelerated world day clock. Not stepping while paused freezes it. The saved float can leave about20 microseconds after600 repeated fixed-step subtractions, so native countdown discards residuals of at most.0001 seconds. This is a bounded float-clock adapter; tests require599 fixed steps still blocked and600 ready. PECSv13 retains the v12 payload and appends the four-byte medpack cooldown; older saves infer0. The save module separately validates its finite0..10 range.

`pe_game_item_cooldown` gives the UI the authoritative timer for916/925; unsupported items return0. The existing quickbar overlay now displays either supported timer. This does not recover source effect420, sounds, the complete consumable catalog, buff interactions with other medicines, or a new tutorial item-use path.
